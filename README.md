# Khulani Special School Management and Communication System

## Project Overview

The Khulani Special School Management and Communication System (KSSMCS) is a proposed software solution designed to centralise learner management, attendance, health and safety records, communication and administrative activities.

## Client

Khulani Special School  
KwaMduku/Mduku, Hluhluwe, KwaZulu-Natal

## Technologies

- ASP.NET Core Web API
- C#
- React
- React Native
- PostgreSQL
- JWT Authentication
- Role-Based Access Control
- GitHub Actions

## Project Structure

- `backend/` – ASP.NET Core Web API
- `web/` – React web application
- `mobile/` – React Native mobile application
- `database/` – Database scripts and documentation
- `documentation/` – System documentation and diagrams
- `tests/` – Testing resources
